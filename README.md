# Discrete Dynamics Experiments

Интерактивное веб-приложение для исследования **разностных уравнений дискретной динамики** вида

```
x(n+1) = f(x(n), μ)
```

Позволяет построить **лестницу Ламерея** (диаграмму «паутина», cobweb plot) и **график зависимости xₙ от n** для произвольной итерируемой функции, заданной формулой.

## Возможности

- Произвольная формула `f(x, μ)` — синтаксис [math.js](https://mathjs.org/docs/expressions/) (по умолчанию логистическое отображение `mu*x*(1-x)`).
- Лестница Ламерея: графики `y = f(x)`, диагональ `y = x` и траектория итераций.
- График временного ряда `xₙ` от `n` с точками.
- Число итераций `N` и число точек дискретизации графика `f(x)` настраиваются.
- Диапазон по оси `x` — автоматически (по данным, с отступом 15%) или вручную через `xmin` / `xmax`.
- Проверка ввода: ошибки формулы и нечисловые/бесконечные значения отображаются под кнопкой «Построить».
- Поддержка символа `μ` (и кириллического «мю») в формуле — автоматически заменяется на `mu`.

## Быстрый старт

Приложение — полностью статическое, сборка не требуется. Единственное условие: его нужно открыть **через HTTP(S)**, а не через `file://`, иначе ES-модули не загрузятся (и нужен интернет для CDN с Plotly и math.js).

Вариант 1 — Python:

```bash
python3 -m http.server 8000
```

Вариант 2 — Node.js:

```bash
npx serve .
```

Затем откройте <http://localhost:8000> в браузере.

## Использование

1. В поле «Формула f(x, mu)» введите функцию; аргументами служат `x` и параметр `mu`.
2. Задайте `mu`, начальное значение `x0` и число итераций `N`.
3. (Опционально) укажите `xmin` / `xmax` — иначе диапазон определится автоматически.
4. Нажмите «Построить».

Примеры формул:

| Система | Формула |
|---|---|
| Логистическое отображение | `mu*x*(1-x)` |
| Квадратичное отображение | `x^2 + mu` |
| Отображение удвоения (tent map) | `mu*min(x, 1-x)` |
| Синусоидальное отображение | `mu*sin(pi*x)` |
| Отображение экони (экспоненциальное) | `exp(mu*(1 - x))` |

## Структура проекта

```
index.html        — страница приложения (разметка, подключение CDN и js/main.js)
css/styles.css    — стили
js/main.js        — точка входа: UIController + PlotManager + App
js/app.js         — App: валидация ввода, расчёт, вызов отрисовки
js/model.js       — IterationModel: итерации xₙ и путь лестницы Ламерея
js/expression.js  — ExpressionFunction: парсинг/компиляция формулы через math.js
js/plots.js       — PlotManager: графики Plotly (лестница и xₙ от n), auto-resize
js/ui.js          — UIController: чтение полей ввода, вывод ошибок
js/utils.js       — linspace, autoRangeFromData, normalizeFormula, проверки чисел
```

## Технологии

- Чистый HTML/CSS, ES-модули — без фреймворков и сборки.
- [Plotly.js](https://plotly.com/javascript/) 2.35.2 — графики (с CDN).
- [math.js](https://mathjs.org/) 12.4.2 — разбор и вычисление формул (с CDN).
